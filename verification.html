Verification and build checks

Automated checks run before merge and before Pages deployment.

Reproducible local commands

python scripts/build_data.py
python scripts/build_site.py
python -m unittest discover -s tests -v
python scripts/check_site.py

Checks enforced

  • 32 methods × 40 amounts = 1,280 cost rows; exact USD 10,000–400,000 grid.
  • Unknown numeric USD costs remain null/empty; every row has a registered official source URL.
  • Canonical JSON/CSV reproducibility; 1,344-line legacy audit and 2,633-line archived main snapshot audit coverage.
  • Local links and anchors, source-required table rows, one h1, landmarks, skip link, table captions, th scope, no JavaScript dependency.
  • Responsive CSS rules: focus-visible, horizontal table scroll, media queries and reduced motion.

Deployment gate

The GitHub Pages workflow rebuilds data and the static dashboard, runs unit tests and the full site check, then uploads/deploys only from main. See GitHub Actions and live site.
