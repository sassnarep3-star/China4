# China4

A static, source-linked research dashboard for US citizens considering how to move funds from mainland China. Open `index.html` locally or visit [GitHub Pages](https://sassnarep3-star.github.io/China4/). The dashboard is educational, not personalized legal or tax advice; unresolved issues are on the Flagged for Review page.

No build or third-party runtime is required. Every substantive table row links to an official source. Historical guidance and individual eligibility should be checked with qualified advisers and the bank.
